# LiLi (v0.2) — Asistente doméstico privado para gestión de tareas

LiLi es un asistente doméstico **bajo mi control**, diseñado para funcionar en **local** o sobre **infraestructura propia**, priorizando privacidad, transparencia y modularidad.

Esta **segunda versión (MVP)** se centra en construir el **núcleo del sistema** mediante un caso de uso sencillo: **gestionar tareas y recordatorios**.

El objetivo es poder **crear, consultar, modificar y completar tareas**, además de programar recordatorios, dejando preparada una arquitectura que permita añadir posteriormente distintas interfaces como **web, móvil o voz**, así como futuras integraciones con la domótica del hogar.

La implementación principal estará basada en **TypeScript / NestJS**, manteniendo una arquitectura modular que permita incorporar otros lenguajes o servicios cuando aporten una ventaja real.
